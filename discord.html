Design system

Discord

An analysis of Discord's design language — a loud, playful gaming-native system built on a deep-indigo canvas lit by Blurple, electric green, and vibrant magenta gradients. Heavy ABC Ginto Nord display type shouts in all-caps over generously rounded media, gradient feature panels, and full-bleed Blurple bands; the mood is arcade-energetic, never corporate.

Source: getdesign.md/design-md/discord/DESIGN.md · rendered as an unofficial static reference for readability, not affiliated with Discord.
